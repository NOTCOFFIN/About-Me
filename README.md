## Zenith Client

**Status:** Prototype / In Development
**Type:** Minecraft desktop launcher

Zenith Client is a modern Minecraft launcher project with a built\-in AI assistant\. The goal is to make launching, customizing, and troubleshooting Minecraft easier from one clean desktop application\.

### What I worked on

- Modern launcher UI and navigation
- Home, News, Mods, Store, Multiplayer, and Settings sections
- Multi\-version Minecraft support planning
- Microsoft authentication
- Fabric / Forge / NeoForge support planning
- Mod management
- AI\-assisted mod search and installation
- Launcher architecture and debugging
- Website and branding concepts

![Zenith Client roadmap](assets/projects/zenith-client-roadmap.png)

**Tech explored:** React, TypeScript, Vite, Electron, minecraft\-launcher\-core, MSMC

## Rock Blaster

**Status:** Playable foundation / In Development
**Type:** Roblox game

Rock Blaster is a wave\-defense and cannon\-upgrade Roblox game project\.

### What I worked on

- Multiplayer lane system for up to 8 players
- Cannon shooting with mouse and touch controls
- Server\-authoritative damage and fire\-rate validation
- Moving rocks with health
- Multiple rock types and bosses
- Wave progression and special waves
- Coins and Crystal rewards
- Cannon upgrades
- Persistent player data
- UI and visual effects
- Rojo workflow with Roblox Studio

**Tech:** Roblox Studio, Luau, Rojo, DataStoreService
