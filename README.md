Zenith Client

Status: In Development / Prototype

Zenith Client is my Minecraft launcher project.

I started it because I wanted to learn how a proper desktop launcher works while creating something with a polished gaming-client style.

I’ve worked on:

* Launcher UI
* Home, News, Mods, Store, Multiplayer and Settings pages
* Electron desktop integration
* Minecraft launching
* Mod management concepts
* Microsoft/Minecraft authentication
* An AI-assisted mod installation idea

I’ve run into plenty of problems while developing it, including dependency issues, Java configuration, Electron white screens, incorrect project paths, and Minecraft launch problems.

Working through those issues has been a major part of learning how larger software projects actually work.
